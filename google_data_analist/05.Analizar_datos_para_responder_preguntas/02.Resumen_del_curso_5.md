Contenido del curso
Este curso se divide en cuatro módulos. Aquí tienes una visión general de las habilidades que adquirirás en cada módulo:

Módulo 1: Organizar los datos para un análisis más eficaz

Organizar los datos facilita su uso en un análisis. En esta parte del curso, aprenderá la importancia de organizar los datos mediante la clasificación y el filtrado. Explorarás la organización de datos tanto en hojas de cálculo como con consultas SQL y tablas temporales.

Módulo 2: Formatear y ajustar datos

 A medida que se acerque el momento de analizar los datos, querrá tenerlos formateados y listos para usar. En esta parte del curso, aprenderá todo sobre la conversión y el formateo de datos, incluido cómo utilizar consultas SQL para combinar datos. También descubrirás el valor de la retroalimentación y el apoyo de tus colegas y cómo puede conducir a nuevos conocimientos que puedes aplicar a tu trabajo.

Módulo 3: Agregar datos para el análisis

Durante un análisis, es posible que necesite combinar datos para obtener información y completar los objetivos empresariales. En esta parte del curso, explorará las funciones, procedimientos y sintaxis para combinar o agregar datos. Aprenderá a combinar datos en varias celdas de hojas de cálculo y en varias tablas de bases de datos mediante consultas SQL.

Módulo 4: Realizar cálculos de datos 

Los cálculos son una de las tareas más comunes que realizan los analistas de datos durante un análisis. En esta parte del curso, explorará fórmulas, funciones y tablas dinámicas en hojas de cálculo y consultas SQL. Todas ellas se utilizan en los cálculos de datos. También conocerá las ventajas de utilizar SQL para gestionar tablas temporales de bases de datos.
