# Ponga a prueba sus conocimientos sobre la ordenación de datos en hojas de cálculo

1. ¿Qué función del menú ordena todos los datos de la hoja de cálculo según la Clasificación de una columna específica ordenada?

   <span style="color:#00a32c">**Ordenar hoja**</span>

        Ordenar hoja ordena todos los datos de la hoja de cálculo por el Ranking de una columna específica ordenada. Cuando se utiliza el rango de ordenación, no se reordena nada más en la hoja de cálculo aparte de las celdas especificadas de una columna.

2. Al utilizar la función SORT en hojas de cálculo, ¿qué enunciado devolverá los datos en orden ascendente?

   <span style="color:#00a32c">**TRUE**</span>

        Al utilizar la función SORT en hojas de cálculo, una sentencia TRUE devolverá los datos en orden ascendente.

3. Rellene el espacio en blanco: Una ordenación personalizada consiste en ordenar los Datos en una hoja de cálculo utilizando las condiciones de _____.

   <span style="color:#00a32c">**Mutiples**</span>

        Una ordenación personalizada consiste en ordenar los datos de una hoja de cálculo utilizando varias condiciones. Esto significa que la ordenación se basará en el orden de las condiciones seleccionadas. 

4. ¿Por qué un profesional de los datos seleccionaría Datos tiene una fila de encabezamiento al ordenar los datos en una hoja de cálculo?

   <span style="color:#00a32c">**Para que la primera fila de datos se trate como etiquetas de encabezamiento en lugar de puntos de datos**</span>

        Un profesional de los datos selecciona Datos tiene una fila de encabezado al ordenar los datos en una hoja de cálculo para asegurarse de que la primera fila de datos se trata como etiquetas de encabezado en lugar de puntos de datos.
