# Ponga a prueba sus Conocimientos sobre la Ordenación de Datos con SQL

1. Un analista de datos de un minorista de regalos ordena una lista de velas artesanales por precio, de la más barata a la más cara. ¿Qué enunciado utilizan?

   <span style="color:#00a32c">**ORDER BY candle_price**</span>

        Utilizan ORDER BY candle_price. Una sentencia ORDER BY ordena por defecto en orden ascendente. ORDER BY column_title es la sintaxis de esta consulta.

2. ¿Qué devolverá esta Consulta?

```sql
SELECT *
FROM widgets
ORDER BY 
manufacture_date DESC
```

   <span style="color:#00a32c">**Todas las filas de la tabla de widgets, con los widgets de fabricación más reciente en primer lugar**</span>

        La Consulta devolverá todas las filas de la tabla widgets, ordenadas por la columna manufacture_date en orden descendente. Esto significa que se devolverán primero los widgets de fabricación más reciente.

3. Está trabajando con una tabla de base de datos que contiene datos de empleados. ¿Qué cláusula de ORDER BY ordenará a los empleados por las fechas de contratación más antiguas al principio de la lista?

   <span style="color:#00a32c">**ORDER BY hire_date DESC**</span>

4. ¿Qué Operador SQL permite a un profesional de los datos filtrar por dos condiciones a la vez cuando utiliza una sentencia WHERE?

   <span style="color:#00a32c">**AND**</span>

        El operador AND permite a un profesional de los datos filtrar por dos condiciones a la vez cuando utiliza una sentencia WHERE.
