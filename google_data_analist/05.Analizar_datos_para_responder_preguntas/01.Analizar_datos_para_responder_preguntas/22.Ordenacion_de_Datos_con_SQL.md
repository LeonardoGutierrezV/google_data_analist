# Ordenación y Filtrado de Datos en SQL

Muchas de las operaciones de organización que se realizan en hojas de cálculo también se pueden ejecutar en SQL. Sin embargo, cuando los conjuntos de datos son masivos, las hojas de cálculo pueden bloquearse; es aquí donde SQL acorta los procesos, permitiendo extraer y combinar tablas de forma rápida y eficiente.

### 1. La Cláusula `ORDER BY` (Ordenar por)

Para ordenar los resultados devueltos en una consulta SQL, se utiliza la cláusula `ORDER BY`. Por norma general, esta debe ser **la última cláusula de la consulta**.

* **Orden Ascendente (Por defecto):** Si no se especifica el tipo de orden, SQL organiza los datos de menor a mayor de forma automática.
* **Orden Descendente (`DESC`):** Si se desea invertir el orden (por ejemplo, para ver las fechas de estreno de películas desde las más recientes hasta las más antiguas), se añade la palabra clave `DESC`.

#### Ejemplo de Estructura Básica:

```sql
SELECT *
FROM base_datos.tabla_peliculas
ORDER BY Release_Date DESC;

```

---

### 2. Combinando Filtros y Ordenación (`WHERE` + `ORDER BY`)

Mientras que la ordenación coloca los datos en un orden específico, los filtros los reducen para mostrar únicamente los registros que cumplen con una condición. Esto se logra mediante la cláusula `WHERE`, la cual debe posicionarse **después de `FROM` y antes de `ORDER BY**`.

#### Filtrando por una Condición (Ejemplo: Comedias más recientes):

```sql
SELECT *
FROM base_datos.tabla_peliculas
WHERE Genero = 'Comedia'
ORDER BY Release_Date DESC;

```

---

### 3. Filtros Avanzados con Múltiples Condiciones (`AND`)

Si se requiere restringir aún más la búsqueda, se puede utilizar el operador lógico `AND` dentro de la cláusula `WHERE` para exigir que se cumplan dos o más condiciones al mismo tiempo.

#### Filtrando por dos Condiciones (Ejemplo: Comedias con ingresos superiores a 300 millones, ordenadas por fecha):

```sql
SELECT *
FROM base_datos.tabla_peliculas
WHERE Genero = 'Comedia' 
	AND Ingresos > 300000000
ORDER BY Release_Date DESC;

```

Con estas herramientas, se logra extraer información altamente específica de una base de datos de manera limpia y óptima. El siguiente paso en el aprendizaje consistirá en la conversión, formato y ajuste de los datos para combinar la información eficazmente.

## Conceptos Clave y Definiciones

| Concepto | Definición |
| --- | --- |
| **Asterisco (`*`)** | Carácter comodín utilizado en la instrucción `SELECT` para indicarle a SQL que seleccione y devuelva todas las columnas disponibles en la tabla. |
| **Cláusula ORDER BY** | Comando en SQL que se encarga de reordenar las filas del resultado de una consulta basándose en los valores de una o más columnas especificadas. |
| **Cláusula WHERE** | Comando utilizado para filtrar registros en SQL, permitiendo extraer únicamente las filas que cumplen con una condición o criterio específico. |
| **Operador DESC** | Palabra clave que se añade después de una columna en la cláusula `ORDER BY` para que los datos se organicen en orden descendente (de mayor a menor). |
| **Operador AND** | Conector lógico utilizado en la cláusula `WHERE` para combinar múltiples condiciones; el registro solo se mostrará si cumple todas las condiciones a la vez. |
| **Consulta (Query)** | Una solicitud de datos o información que se realiza a una base de datos utilizando comandos específicos en un lenguaje estructurado como SQL. |
