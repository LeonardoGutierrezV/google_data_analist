# Actividad práctica: Analizar datos meteorológicos en BigQuery

## Resumen de la actividad

Hasta ahora, ha aprendido a utilizar BigQuery para limpiar, preparar y analizar datos. Ahora, consultará un conjunto de datos y guardará los resultados como una nueva tabla. Se trata de una habilidad útil cuando la fuente de datos original y dinámica cambia continuamente y usted necesita conservar un conjunto de datos específico para un análisis continuado. También es valiosa cuando tiene acceso a un gran conjunto de datos y sabe que va a realizar más de un análisis en un subconjunto del conjunto de datos. Cuando complete esta actividad, será capaz de utilizar consultas SQL para crear nuevas tablas cuando se trate de conjuntos de datos complejos.

## Escenareio

Revise el siguiente escenario. A continuación, complete las instrucciones paso a paso.

Usted es Analista de datos en un canal de noticias de Nueva York. Le han encargado que responda a las preguntas sobre el tiempo de los meteorólogos. Trabajará con un conjunto de datos público que contiene resúmenes globales del día (GSOD) de la Administración Nacional Oceánica y Atmosférica (NOAA). El Conjunto de datos GSOD incluye información sobre elementos meteorológicos diarios, como la temperatura media y la velocidad del viento, de más de 9.000 estaciones meteorológicas de todo el mundo. Este Conjunto de datos se actualiza a diario, por lo que, además de ser de gran tamaño, cambia constantemente. Por ello, guardará un subconjunto de los datos sobre la región de Nueva York en una nueva tabla para facilitar su análisis.

## Paso 2. Consulta de los datos

Los meteorólogos con los que está trabajando le han pedido que obtenga la temperatura, la velocidad del viento y las precipitaciones de las estaciones de La Guardia y JFK, para todos los días de 2020. También han solicitado que les presente los datos en orden descendente por fecha y ascendente por ID de estación. Para devolver esta información:

1. Seleccione el botón CONSULTA en la fila de funciones de la pestaña

2. Seleccione la opción En pestaña dividida en el menú desplegable. 

3. Introduzca la siguiente consulta en el Editor de consultas:

```sql
SELECT
  stn,
  date,
  IF(
     temp=9999.9,
     NULL,
     temp) AS temperature,
  IF(
     wdsp="999.9",
     NULL,
     CAST(wdsp AS Float64)) AS wind_speed,
  IF(
     prcp=99.99,
     0,
     prcp) AS precipitation
FROM
  `bigquery-public-data.noaa_gsod.gsod2020`
WHERE
  stn="725030" -- La Guardia
  OR stn="744860" -- JFK
ORDER BY
  date DESC,
  stn ASC
```

**Nota**: Esta consulta utiliza la función IF para sustituir los valores 9999, 999,9 y 99,99 por NULL. La descripción del conjunto de datos explica que estos son los valores por defecto cuando falta la medición.

4. Seleccione EJECUTAR. 

Ahora ha ejecutado la consulta y ha obtenido resultados. Pero estos resultados no se guardan en ninguna parte, por lo que cada vez que quiera examinarlos, tendrá que volver a ejecutar esta consulta.

## Paso.4 Consultar la tabla nueva

Ahora que tiene el subconjunto de estos datos guardado en una nueva tabla, puede utilizar la siguiente consulta para hallar la temperatura media en junio de 2020. En primer lugar, sustituya your_project_name por el nombre de su proyecto en BigQuery.

```sql
SELECT
    AVG(temperature)
FROM
    `your_project_name.demos.nyc_weather`  
WHERE
    date BETWEEN '2020-06-01' AND '2020-06-30'
```

**Nota**: formatee la sintaxis de inicio con el nombre de su proyecto antes de ejecutar esta consulta. Vea el ID completo de la tabla seleccionando en la pestaña Detalles de su nueva tabla de datos nyc_weather.

También puede utilizar esta sintaxis para encontrar la velocidad media del viento o cualquier otra información de este subconjunto de datos. Intente escribir algunas consultas más para responder a las preguntas de los meteorólogos.

La posibilidad de guardar sus resultados en una nueva tabla es útil cuando sabe que sólo le interesa un subconjunto de un conjunto de datos complejo más amplio que piensa consultar varias veces, como los datos meteorológicos sólo de La Guardia y el aeropuerto JFK. Esto también ayuda a minimizar los errores durante su análisis.
