# ¿Qué es el Análisis de Datos?

Hemos aprendido a hacer las preguntas correctas, preparar los datos para su exploración y procesarlos para asegurarnos de que queden impecables. Ahora es el momento del meollo del proceso: **¡el análisis propiamente dicho!**

El análisis es el proceso utilizado para **dar sentido a los datos recopilados**. Significa dar los pasos adecuados para procesar y pensar en sus datos de diferentes maneras. Su objetivo principal es identificar tendencias y relaciones dentro de los datos para responder con precisión a la pregunta planteada.

### Las 4 Fases del Análisis

Para lograr un análisis efectivo, debe ceñirse a cuatro tareas fundamentales:

1. Organizar los datos.
2. Formatearlos y ajustarlos.
3. Obtener información y perspectivas de otras personas.
4. Transformar los datos (observar relaciones entre puntos de datos y realizar cálculos).

---

### Aplicando las Fases a un Escenario Real: El Regalo de Boda

Imagina que quieres comprar un regalo para la boda de tu amiga Zara, pero no sabes qué regalarle. Tienes una tonelada de datos en la web de su boda, pero decides aplicar las fases del análisis para tomar la mejor decisión:

* **1. Organizar los datos:** En lugar de revisar fotos o textos dispersos, vas directamente al registro en línea. El registro actúa como un conjunto de datos ya organizado (una lista de deseos).
* **2. Formatear y ajustar los datos:** Desplazarse por cientos de regalos toma tiempo. Para agilizar las cosas, ajustas los datos: ordenas los precios de menor a mayor y aplicas un filtro para mostrar solo los regalos que entran en tu presupuesto de 60 $.
* **3. Obtener información de otras personas:** Revisas la lista para ver qué artículos ya han sido comprados por otros invitados. Obtener opiniones o aportaciones de los demás es clave porque te ofrecen un punto de vista al que no tenías acceso. En este caso, el esfuerzo colaborativo de los invitados al marcar lo que ya compraron evita que Zara reciba el mismo regalo dos veces.
* **4. Transformar los datos:** Consiste en identificar relaciones y patrones para hacer cálculos. Al cruzar los puntos de datos (lo que le gusta a Zara + lo que se ajusta a tus 60 $ + lo que nadie ha comprado), transformas esa información en una decisión final: el regalo perfecto.

El beneficio del proceso de análisis es que probablemente ya lo aplicas en tu vida cotidiana. Ya sea en lo personal o en lo profesional, estas cuatro tareas te ayudarán a tomar mejores decisiones.

## Conceptos Clave y Definiciones

| Concepto | Definición |
| --- | --- |
| **Análisis de Datos** | El proceso de examinar, limpiar, transformar y modelar datos con el objetivo de descubrir información útil, llegar a conclusiones y respaldar la toma de decisiones. |
| **Organización de Datos** | La fase del análisis que consiste en categorizar y estructurar la información disponible en un lugar o formato específico para que sea accesible. |
| **Formateo de Datos** | El acto de cambiar la disposición, el orden o la visualización de los datos (por ejemplo, mediante filtros o clasificaciones) para que sean más fáciles de digerir. |
| **Filtro de Datos** | Herramienta o proceso que permite ocultar los datos que no cumplen con ciertos criterios específicos, mostrando únicamente la información relevante. |
| **Aportaciones de Terceros** | El acto de recabar perspectivas, opiniones o datos de otras personas (expertas o no) para identificar obstáculos o enriquecer el punto de vista del análisis. |
| **Transformación de Datos** | La etapa del análisis donde se realizan cálculos matemáticos, se combinan variables y se identifican patrones o relaciones entre diferentes puntos de datos. |
