# Importe y combine datos en hojas de cálculo y bases de datos

En lecciones anteriores, descubrió cómo utilizar las funciones IMPORTRANGE y CONCATENATE en las hojas de cálculo. En esta lectura, tendrá la oportunidad de ampliar sus conocimientos sobre estos conceptos a las consultas SQL. 

## Importar datos

Como analista de datos, son muchas las ocasiones en las que necesitará importar datos de un archivo o ubicación a otro. Tanto las hojas de cálculo como SQL incluyen funciones que le permiten importar datos. 

### Importar datos en hojas de cálculo

Como ya ha aprendido, en las hojas de cálculo se utiliza la función IMPORTRANGE para importar un rango de celdas de otra hoja de cálculo a la hoja de cálculo actual. La sintaxis es: **=IMPORTRANGE(spreadsheet_url, range_string)**. 

En esta fórmula, **spreadsheet_url**  es la URL de la hoja de cálculo de la que desea importar datos. Las celdas concretas que desea importar, como A2:B6, se especifican mediante range_string. Si la hoja de cálculo tiene varias pestañas, también deberá especificar el nombre de la pestaña como parte del Rango. 

Un ejemplo de esto es una empresa que necesita hacer un seguimiento de quién ha realizado aportaciones para la jubilación, de modo que pueda asegurarse de que la aportación de la empresa se distribuye correctamente. Los analistas utilizarían IMPORTRANGE para extraer toda la información sobre las cotizaciones de jubilación en una hoja de cálculo que contenga todos los sueldos y primas de los empleados a final de año. Esto les permite determinar qué empleados realizaron aportaciones y tienen derecho a recibir fondos de contrapartida. 

## Importar datos en SQL

A diferencia de las hojas de cálculo, SQL no incluye una función para importar datos. En su lugar, un método que puede utilizar para importar datos de una tabla a otra es utilizar el comando **INSERT INTO** junto con una sentencia **SELECT**. La sintaxis es la siguiente:

```sql
INSERT INTO [destination_table_name]
SELECT [column names, separated by commas, or * for all columns]
FROM [source_table_name]
WHERE [condition]
```

En esta sintaxis, la consulta SQL inserta filas de una tabla de origen en una tabla de destino basándose en la cláusula **WHERE**. 

Por ejemplo, imagine que trabaja para una empresa de venta al por menor que almacena sus ventas y la información de sus clientes en una base de datos SQL. El director de marketing le pide que le proporcione una tabla que contenga los nombres y direcciones de los clientes que no han realizado ninguna compra este año y que viven en códigos postales específicos. Una forma de recopilar esta información es utilizar el comando **INSERT INTO** junto con los comandos **SELECT** y **WHERE**, como se indica a continuación:

```sql
INSERT INTO customer_promotion
SELECT *
FROM customers
WHERE total_sales = 0 AND postal_code = '12345'
```

## Combinar datos

Otra herramienta de su juego de herramientas de analista de datos es su capacidad para unir dos o más cadenas de texto que estén almacenadas en columnas o campos separados. Por ejemplo, puede que desee combinar el nombre y los apellidos de un cliente para crear etiquetas de correo para una promoción de marketing. Tanto en hojas de cálculo como en SQL, la unión de cadenas de texto se denomina concatenación. 


### Combinar datos en hojas de cálculo
En las hojas de cálculo, se utiliza la función **CONCATENATE** para unir dos o más cadenas de texto, como por ejemplo combinar las direcciones de las calles y los contactos principales en la base de datos de proveedores de una empresa. 

La sintaxis básica es **=CONCATENATE(item 1, item 2)**. Puede añadir varios elementos separándolos con comas. Cuando proceda, como cuando combina el nombre y los apellidos de un cliente, debe añadir un espacio entre los elementos que está combinando escribiendo comillas [" "] entre los elementos. Separe también esta información con una coma. Esto cambiaría la fórmula a: =CONCATENATE(item 1, " ", item 2). 

### Combinar datos en SQL

En SQL, utilice la función CONCAT para unir cadenas y crear nuevas cadenas de texto. Puede combinar datos simplemente para mejorar la legibilidad de los informes (como combinar el nombre y el apellido de un cliente al generar una lista de clientes). O bien, podría combinar datos para generar un identificador único para las filas de una tabla. He aquí la sintaxis básica:

```sql
SLECT CONCAT(field1, " ", field2)
FROM [table_name]
```

Observe que esta sintaxis incluye " " para que haya un espacio entre los campos combinados. Con esta sintaxis, SQL combina campo1 y campo2 con un espacio entre ellos. 

Por defecto, SQL incluye los nombres de los campos como encabezados cuando ejecuta una consulta. Sin embargo, si utiliza la función CONCAT, SQL no sabe qué utilizar como encabezado. Por este motivo, debe incluir un alias para los campos combinados para facilitar la legibilidad. Puede dar un alias a los campos combinados utilizando AS:

```sql
SELECT CONCAT(field1, " ", field2) AS alias 
FROM [table_name]
```

Por ejemplo, si tiene previsto utilizar CONCAT para combinar el nombre y los apellidos de los Clientes de su empresa en una única expresión, podría utilizar esta consulta:

```sql
SELECT CONCAT(first_name, " ", last_name) AS Customer_Name
FROM [table_name]
```

## Claves

Los Datos pueden importarse y combinarse tanto en hojas de cálculo como en bases de datos SQL. Para importar datos a una hoja de cálculo, utilice la función IMPORTRANGE. Para importar datos a una tabla SQL, utilice los comandos INSERT INTO, SELECT y WHERE. Utilice CONCATENATE para combinar dos o más cadenas de datos en hojas de cálculo. En SQL, utilice la función CONCAT para combinar campos.
