## Paso 2. Por que utilizar CONCAT y CONCATENATE

Ocasionalmente, se encontrará con un conjunto de datos con valores de datos en celdas separadas que desee combinar como un único valor en una sola celda. Esto es habitual cuando se trata de nombres y fechas. El conjunto de datos puede tener columnas separadas para nombres y apellidos, pero es posible que desee una columna con los nombres completos.

También suele ser conveniente tener juntas las combinaciones de ciudad / estado y mes / año, ya que es probable que se registren juntas.

La función **CONCAT** de las hojas de cálculo puede combinar este tipo de datos.
