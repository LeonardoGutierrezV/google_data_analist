# Manipulación de Cadenas y Consultas Avanzadas en SQL: La Función CONCAT

¡Me alegro de volver a verte! Así como en las hojas de cálculo utilizamos funciones como `CONCATENATE` (Concatenar) para unir dos o más cadenas de texto, en SQL contamos con una función similar que nos permite fusionar información de varias fuentes y columnas: la función **`CONCAT`**.

Para ilustrar cómo funciona, utilizaremos datos abiertos de *Citi Bike*, el sistema público de bicicletas compartidas en Nueva York. El objetivo será descubrir cuáles son las rutas más populares entre los diferentes tipos de usuarios (clientes de una sola vez frente a suscriptores).

---

### Construcción de una Consulta Compleja en SQL

Para responder a nuestro problema, necesitamos combinar los nombres de las estaciones de inicio y finalización en una sola cadena de texto reconocible como "Ruta", contar los viajes y promediar su duración.

#### 1. Selección y Combinación de Cadenas (`SELECT` + `CONCAT`)

* Iniciamos seleccionando la columna del tipo de usuario.
* Usamos **`CONCAT(start_station_name, end_station_name)`** para fusionar el origen y el destino de cada viaje.
* Aplicamos el alias **`AS route`** para darle un nombre limpio y legible a esta nueva columna calculada.

#### 2. Conteo de Registros (`COUNT`)

* Utilizamos la función **`COUNT(*)`** con un asterisco. Como en este conjunto de datos cada fila representa un viaje individual, esto nos permite contar el total de filas seleccionadas.
* Nombramos esta columna de salida como **`AS num_trips`**.

#### 3. Cálculos Numéricos Avanzados (`ROUND` + `AVG` + `CAST`)

* Queremos calcular la duración promedio del viaje, pero sin lidiar con demasiados decimales.
* Utilizamos **`AVG`** para obtener el promedio y lo envolvemos dentro de la función **`ROUND`** (Redondear).
* Para asegurar que el cálculo se procese de forma óptima, convertimos los datos de duración a números enteros usando la estructura **`CAST(... AS INT64)`**. *Nota: BigQuery almacena los números enteros en un sistema de memoria de 64 bits.*
* Configuramos la función `ROUND` con un `, 2` al final para limitar el resultado a dos decimales y renombramos la salida como **`AS duracion`**.

#### 4. Agrupación y Ordenamiento de los Datos (`GROUP BY` + `ORDER BY`)

* **`FROM`:** Indicamos la ubicación exacta de la base de datos de *Citi Bike*.
* **`GROUP BY`:** Debido a que estamos usando funciones de agregación (como `COUNT` y `AVG`), es obligatorio agrupar las filas de resumen. Agrupamos por la estación de inicio, la estación final y el tipo de usuario.
* **`ORDER BY num_trips DESC`:** Organizamos los resultados basándonos en la columna del número de viajes en orden descendente (de mayor a menor).
* **`LIMIT 10`:** Restringimos la salida para mostrar únicamente el *top 10* de las rutas más comunes.

### El Impacto del Análisis

Gracias a `CONCAT`, las coordenadas o identificadores abstractos se transforman en nombres de rutas fáciles de rastrear en lugares reales. Esto ayuda a la empresa a entender el comportamiento de su base de usuarios y a tomar decisiones estratégicas, como determinar en qué estaciones específicas de la ciudad se necesitan más bicicletas disponibles.

## Conceptos Clave y Definiciones

| Concepto | Definición |
| --- | --- |
| **Cadena de Texto (String)** | Un grupo o secuencia de caracteres (letras, números o símbolos) que las bases de datos y hojas de cálculo interpretan como texto. |
| **Función CONCAT** | Comando de SQL que se utiliza para unir o concatenar dos o más expresiones de texto en una sola columna. |
| **Datos Abiertos (Open Data)** | Filosofía y práctica que promueve el acceso, uso, reutilización y uso compartido de datos de forma completamente libre y gratuita para cualquier persona. |
| **Alias (`AS`)** | Palabra clave en SQL que se emplea para asignarle un nombre temporal y más legible a una columna o tabla dentro de los resultados de una consulta. |
| **Función ROUND** | Función matemática que redondea un número con decimales al número de posiciones decimales específicas que el analista determine. |
| **INT64** | Tipo de dato numérico en sistemas como BigQuery que representa un número entero (sin decimales) almacenado en un formato de memoria de 64 bits. |
| **Cláusula GROUP BY** | Sentencia de SQL que agrupa las filas que tienen los mismos valores en columnas específicas para poder realizar operaciones de resumen sobre ellas. |
| **Cláusula LIMIT** | Comando que restringe el número máximo de filas o registros que una consulta de SQL puede devolver en su pantalla de resultados. |
