# Desafío del módulo 2

1. Rellene el espacio en blanco: Un analista de datos junior de una organización sanitaria utiliza la función de la hoja de cálculo _____ para localizar caracteres específicos de los números de cuenta de los proveedores de seguros.

   <span style="color:#00a32c">**FIND**</span>


2. Un analista de datos trabaja con una hoja de cálculo que contiene información sobre un producto que suele tener cadenas de texto muy largas. Para comprobar la coherencia, utilizan una función para contar el número de caracteres de la celda P12. ¿Cuál es la sintaxis correcta de la función?

   <span style="color:#00a32c">**=LEN(P12)**</span>

3. Usted utiliza una hoja de cálculo para organizar una lista de las próximas tareas en el trabajo. La columna A contiene la lista de tareas y la columna B anota su prioridad: alta, media o baja. ¿Qué herramienta de hoja de cálculo creará una lista desplegable con las prioridades de la columna B?

   <span style="color:#00a32c">**Validación de datos**</span>

4. Un analista trabaja con datos financieros que están formateados como números, pero deberían estar formateados como dólares estadounidenses. ¿Qué herramienta de hoja de cálculo debería utilizar para corregir el formato?

   <span style="color:#00a32c">**El acceso directo "Formato como Moneda**</span>

5. Usted utiliza una base de datos SQL para evaluar la eficacia de los viajes compartidos. La tabla de la base de datos contiene una columna de ubicaciones de recogida y otra columna de ubicaciones de entrega. ¿Qué función combinará las ubicaciones de recogida y entrega en una nueva columna? 

   <span style="color:#00a32c">**CONCAT**</span>

6. Un analista de datos de una orquesta sinfónica utiliza una hoja de cálculo para hacer un seguimiento de cuántos conciertos requieren más de 65 músicos. ¿Qué herramienta de la hoja de cálculo pueden utilizar para cambiar la forma en que aparecen las celdas cuando los valores son iguales o superiores a 65?

   <span style="color:#00a32c">**Formato condicional**</span>

7. Rellene el espacio en blanco: Un Analista de datos que analiza los puntos de ebullición de varios líquidos utiliza la función SQL _____ para ajustar 356,727801 °C con sólo tres decimales. 

   <span style="color:#00a32c">**ROUND**</span>

8. La Célula de cálculo L2 contiene la cadena de texto Función. Para devolver la subcadena Fun, ¿cuál es la sintaxis correcta?

   <span style="color:#00a32c">**=LEFT(L2, 3)**</span>
