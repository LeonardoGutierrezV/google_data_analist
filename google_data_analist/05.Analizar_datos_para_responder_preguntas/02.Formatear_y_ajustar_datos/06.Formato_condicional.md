# Combinando el Formato Condicional y la Validación de Datos

El **formato condicional** es una herramienta de hoja de cálculo que cambia la apariencia de las celdas cuando sus valores cumplen con condiciones específicas. Esto permite añadir **señales visuales** que facilitan la comprensión de una tabla de un vistazo, haciendo que la información sea más clara para cualquier parte interesada (*stakeholder*).

Al combinar el formato condicional con la **validación de datos**, podemos crear herramientas personalizadas avanzadas para nuestras hojas de cálculo.

---

### Caso Práctico 1: Codificación por Colores para la Columna de "Estado"

Cuando una tabla de seguimiento de proyectos crece demasiado, se vuelve difícil procesar cuántas tareas están pendientes o completadas. Utilizando los menús desplegables previamente creados con la validación de datos, podemos aplicar colores estratégicos:

* **Paso 1:** Ir a la opción de *Formato condicional* dentro del menú **Formato**.
* **Paso 2:** Seleccionar el rango de celdas correspondiente a la columna "Estado" (Columna C).
* **Paso 3:** En las reglas de formato, elegir la condición *"El texto es exactamente"*.
* **Paso 4:** Configurar las reglas y los colores correspondientes:
* Si el texto es exactamente **«Aún no se ha iniciado»** $\rightarrow$ Relleno **Rojo**.
* Si el texto es exactamente **«En curso»** $\rightarrow$ Relleno **Amarillo**.
* Si el texto es exactamente **«Listo»** $\rightarrow$ Relleno **Verde**.



**Resultado:** Una señal visual inmediata que indica el progreso real del proyecto sin necesidad de leer celda por celda.

---

### Caso Práctico 2: Seguimiento de Plazos y Fechas Límite

También podemos combinar ambas herramientas para controlar y resaltar las fechas de vencimiento en una columna llamada "Revisar antes de esta fecha":

1. **Validación de entrada:** Primero, usamos la *Validación de datos* (Menú **Datos**) y seleccionamos el criterio **Fecha** para asegurarnos de que los usuarios solo introduzcan fechas válidas y no texto común.
2. **Regla condicional temporal:** En el menú de *Formato condicional*, seleccionamos la columna de fechas y elegimos la regla **"La fecha es posterior a"**.
3. **Criterio dinámico:** Seleccionamos la opción **«hoy»** y asignamos el color **Naranja**.

**Resultado:** Todas las próximas fechas de revisión cambian de color automáticamente día con día, alertando al equipo sobre los plazos futuros de manera clara.

> **Nota de la herramienta:** Programas de hojas de cálculo como Microsoft Excel cuentan con estas reglas de códigos de colores ya integradas y listas para usarse. La experimentación con estas combinaciones te permitirá personalizar las tablas según las necesidades de cualquier equipo.

## Conceptos Clave y Definiciones

| Concepto | Definición |
| --- | --- |
| **Formato Condicional** | Característica de las hojas de cálculo que aplica automáticamente un formato visual (como color de fondo, estilo o fuente) a las celdas que cumplen con ciertos criterios establecidos. |
| **Señales Visuales** | Elementos gráficos (colores, iconos o fuentes) que ayudan al ojo humano a procesar, categorizar e interpretar grandes volúmenes de datos de manera casi instantánea. |
| **Criterio de Texto Exacto** | Regla de filtrado o formato que se activa únicamente si el contenido de la celda coincide letra por letra con la cadena de texto especificada (sensible a variaciones). |
| **Validación de Fecha** | Restricción técnica que obliga a la celda a recibir únicamente valores en formato cronológico (año/mes/día), rechazando entradas de texto mal escritas o inválidas. |
| **Regla de Fecha Dinámica** | Condición que utiliza el tiempo presente del sistema informático (como el criterio "hoy") para evaluar y cambiar el formato de los datos en tiempo real. |
