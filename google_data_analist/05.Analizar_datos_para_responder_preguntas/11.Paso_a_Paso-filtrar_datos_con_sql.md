## Ejemplo 1. Filtrar datos en SQL Filtrar datos en SQL

Siga los siguientes pasos para utilizar la cláusula WHERE para filtrar la base de datos y limitar la lista a las películas del género comedia.

1. En el panel Explorador de BigQuery, seleccione el conjunto de datos de películas y, a continuación, la tabla de películas . 

2. Seleccione la pestaña Vista previa del panel Detalles.

3. Seleccione Query y luego In new tab e introduzca el siguiente código en el editor de consultas:

```sql
SELECT *
FROM `projectID.movie_data.movies`
```

**Nota**: Si está completando este código en BigQuery, sustituya projectID en el bloque de código por su propio projectID.

4. Utilice la cláusula WHERE para filtrar los datos. Introduzca WHERE Genre = 'Comedy'; para filtrar y seleccionar las filas con "Comedia" en la columna Género.

5. Ahora su código debería coincidir con este bloque de código:

```sql
SELECT *
FROM `projectID.movie_data.movies`
WHERE Genre = 'Comedy';
```
6. Seleccione EJECUTAR para ejecutar la consulta. Los resultados muestran una lista más corta de películas, todas del género comedia.
