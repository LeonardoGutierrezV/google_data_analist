# Cuando los Datos no están fácilmente disponibles

Anteriormente, aprendió cómo puede hacer un análisis utilizando datos proxy si no tiene datos. Es posible que tenga algunas preguntas sobre los datos proxy, por lo que esta lectura le dará algunos ejemplos más de los tipos de conjuntos de datos que pueden servir como fuentes de datos alternativas.

## Ejemplos de datos proxy

A veces, los datos que respaldan un objetivo empresarial no están fácilmente disponibles. Es entonces cuando resultan útiles los datos proxy. Eche un vistazo a los siguientes escenarios y al lugar que ocupan los datos proxy en cada ejemplo:

| Escenario Negocio a negocio (Business-to-Business) | Cómo pueden utilizarse los datos proxy |
| --- | --- |
| Un nuevo modelo de coche acaba de lanzarse hace unos días y el concesionario de automóviles no puede esperar hasta final de mes a que lleguen los datos de ventas. Quieren proyecciones de ventas ahora. | El analista toma como proxy el número de clics a las especificaciones del coche en la página web del concesionario como estimación de las ventas potenciales en el concesionario. |
| Un nuevo producto cárnico de origen vegetal se ha almacenado recientemente en las tiendas de comestibles y el proveedor necesita estimar la demanda en los próximos cuatro años. | El analista toma como proxy los datos de ventas de un sustituto del pavo hecho de tofu que lleva varios años en el mercado. |
| La Cámara de Comercio quiere saber cómo va a repercutir una campaña turística en los viajes a su ciudad, pero los resultados de la campaña aún no están a disposición del público. | El analista proxy los datos históricos de reservas aéreas a la ciudad entre uno y tres meses después de que se realizara una campaña similar seis meses antes. |

## Conjuntos de datos abiertos (públicos)

Si forma parte de una gran organización, es posible que tenga acceso a muchas fuentes de datos. Pero si busca algo específico o un poco fuera de su línea de negocio, también puede recurrir a conjuntos de datos abiertos o públicos. (Puede consultar este [artículo](https://medium.com/thinkdata/is-there-a-difference-between-open-data-and-public-data-2b8d5608b2f1) de Medium para obtener una breve explicación de la diferencia entre datos abiertos y públicos)

He aquí un ejemplo. Recientemente se ha puesto a disposición del público una versión nasal de una vacuna. Una clínica quiere saber qué puede esperar de las contraindicaciones, pero acaba de empezar a recopilar Datos de primera fuente de sus pacientes. Una contraindicación es una condición que puede hacer que un paciente no tome una vacuna debido al daño que le causaría si la tomara. Para estimar el número de posibles contraindicaciones, un analista de datos toma como proxy un conjunto de datos abiertos de un ensayo de la versión inyectable de la vacuna. El analista selecciona un subconjunto de los datos con los perfiles de pacientes que más se aproximan a la composición de los pacientes de la clínica.

Hay muchas formas de compartir y colaborar en torno a los Datos dentro de una comunidad. [Kaggle](
kaggle.com), que ya presentamos anteriormente, dispone de conjuntos de datos en una gran variedad de formatos, incluido el tipo más básico, los Archivos CSV (Valores separados por coma).

ASÍ COMO CON CUALQUIER OTRO TIPO DE CONJUNTO DE DATOS, esté atento a los datos duplicados y a los "Nulos" en los conjuntos de datos abiertos. Nulo suele significar que un campo de datos no se asignó (se dejó vacío), pero a veces Nulo puede interpretarse como el valor, 0. Es importante entender cómo se utilizó Nulo antes de empezar a analizar un conjunto de datos con datos Nulos. 

## Puntos clave

Mientras trabaja en proyectos de análisis de datos, a menudo pueden utilizarse datos proxy para estimar o predecir resultados cuando no se dispone de datos reales. Los conjuntos de datos abiertos o públicos pueden utilizarse como fuentes de datos proxy, y hay muchos repositorios en línea disponibles para encontrar conjuntos de datos relevantes. Pero sea prudente al utilizar datos proxy y asegúrese de que se adaptan bien al propósito previsto. Por último, compruebe si hay Datos duplicados y valores Nulos en los conjuntos de datos abiertos antes de utilizarlos para el análisis.
