# Paso a paso: Más técnicas de limpieza de datos

Esta lectura esboza los pasos que el instructor realiza en el siguiente vídeo, [Aún más técnicas de limpieza de datos](https://www.coursera.org/learn/process-data/lecture/Ei2IH/even-more-data-cleaning-techniques). Este vídeo le enseña diferentes métodos que utilizan los analistas de datos en el mapeo de datos. El mapeo de datos es el proceso de emparejar campos de una base de datos a otra. Es fundamental para el éxito de la migración de datos, la integración de datos y muchas otras actividades de gestión de datos. Este vídeo contiene una actividad para que practiques.

Mantenga abierta esta guía paso a paso mientras ve el vídeo. Puede servirle como referencia útil si necesita contexto o aclaraciones adicionales mientras sigue los pasos del vídeo. No se trata de una actividad puntuable, pero puedes completar estos pasos para practicar la habilidad demostrada en el vídeo.

## Ejemplo: CONCATENATE

**CONCATENATE** es una función que une dos o más cadenas de texto. En el vídeo, aprenderá a utilizar CONCATENATE para limpiar los datos después de combinar dos conjuntos de datos.

1. Abra la hoja de cálculo del conjunto de datos titulada Asociación Global de Logística. Cuando se le solicite, seleccione USAR PLANTILLA. 

2. Inserta una nueva columna a la derecha de la columna E. Etiquétala como Nueva Dirección en la celda F1.

3. En la segunda fila de la nueva columna (celda F2), introduce =CONCATENATE (D2,E2) y pulsa Intro. 

   **a.** Observarás que algunos resultados necesitan un espacio entre la dirección y el número de unidad o suite, como por ejemplo: 25 Dyas RdSte. 101.

   **b.** Podría limpiar manualmente los datos más tarde para añadir un espacio entre Rd y Ste., pero CONCATENATE puede hacerlo por usted. 

   **c.** La fórmula CONCATENATE puede ayudarle a dar formato a los datos a medida que se combinan introduciendo una cadena adicional para insertar un espacio entre Rd y Ste.

   **d.** Introduzca =CONCATENATE(D2, " ", E2) y obtendrá una dirección con el siguiente formato: 25 Dyas Rd Ste. 101. ¡Mucho mejor!

4. Asegúrate de que los nuevos datos de la celda reflejan fielmente la fusión de las dos columnas anteriores. 

5. Selecciona la celda F2 y arrastra hacia abajo para aplicar la fórmula a todas las filas de la columna.
