# Ponga a prueba sus conocimientos sobre limpieza de datos en hojas de cálculo

1. ¿Cuál es la relación entre una Cadena de texto y una Subcadena?

   <span style="color:#00a32c">**Una cadena de texto es un grupo de caracteres dentro de una celda. Una subcadena es un subconjunto más pequeño de esa cadena de texto.**</span>

        Una cadena de texto es un grupo de caracteres dentro de una celda. Una subcadena es un subconjunto más pequeño de esa cadena de texto.

2. Un analista de datos utiliza la función COUNTIF para contar el número de veces que aparece un valor inferior a 50 entre las celdas D2 a F100 de la hoja de cálculo. ¿Cuál es la sintaxis correcta? 

   <span style="color:#00a32c">**=COUNTIF(D2:F100,"<50")**</span>

        La sintaxis correcta es =COUNTIF(D2:F100,"<50"). COUNTIF devolverá el número de celdas que coinciden con un valor. D2:F100 es el rango. Y “<50” es el valor especificado.

3. Rellene el espacio en blanco: Para eliminar los espacios iniciales, finales y repetidos en los Datos, los analistas utilizan la función ____. 

   <span style="color:#00a32c">**TRIM**</span>

        TRIM es una función que elimina los espacios iniciales, finales y repetidos en los datos.
