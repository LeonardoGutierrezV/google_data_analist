# Documentación: Funciones para la Optimización de la Limpieza de Datos

La limpieza de datos mediante funciones permite automatizar la verificación de la integridad, normalizar formatos y corregir errores de entrada de manera eficiente en hojas de cálculo.

## 1. Validación de Rangos y Valores

Estas funciones ayudan a identificar datos atípicos, errores de signo o valores que se salen de los parámetros lógicos de negocio.

* **COUNTIF (CONTAR.SI):** Devuelve el número de celdas que cumplen con un criterio específico dentro de un rango.
* **Utilidad:** Identificar valores negativos, ceros accidentales o importes que superan un límite máximo.
* **Sintaxis:** `=COUNTIF(rango, "condición")`
* **Ejemplo:** `=COUNTIF(I2:I72, "<100")` detecta entradas erróneas por debajo del precio mínimo.



## 2. Verificación de Longitud y Formato

Garantiza que los identificadores o códigos cumplan con una estructura predefinida.

* **LEN (LARGO):** Cuenta el número total de caracteres en una cadena de texto.
* **Utilidad:** Validar que códigos de identificación (IDs) tengan el número exacto de dígitos requerido.
* **Sintaxis:** `=LEN(rango)`
* **Sugerencia pro:** Combinar con **Formato Condicional** para resaltar visualmente aquellas celdas cuya longitud no coincida con el estándar (ej. resaltar si la longitud es distinta de 6).



## 3. Extracción de Subcadenas

Permiten desglosar celdas que contienen información combinada para analizarlas por separado.

* **LEFT (IZQUIERDA):** Extrae un número determinado de caracteres desde el inicio (izquierda) de una cadena.
* **Sintaxis:** `=LEFT(rango, número_de_caracteres)`


* **RIGHT (DERECHA):** Extrae caracteres desde el final (derecha) de una cadena.
* **Sintaxis:** `=RIGHT(rango, número_de_caracteres)`


* **MID (EXTRAE/MED):** Extrae un segmento específico de la mitad de una cadena basándose en una posición inicial.
* **Sintaxis:** `=MID(rango, posición_inicial, número_de_caracteres)`
* **Ejemplo:** Extraer solo la abreviatura del estado en un código que incluye Ciudad-Estado-ID.



## 4. Manipulación y Unión de Texto

Funciones para reconstruir datos o corregir problemas de formato visual y estructural.

* **CONCATENATE (CONCATENAR):** Une dos o más cadenas de texto en una sola celda.
* **Utilidad:** Volver a unir códigos que fueron separados previamente o combinar nombres y apellidos.
* **Sintaxis:** `=CONCATENATE(cadena1, cadena2, ...)`


* **TRIM (ESPACIOS):** Elimina espacios sobrantes al inicio, al final o espacios dobles entre palabras.
* **Utilidad:** Corregir errores de importación que impiden realizar búsquedas precisas (VLOOKUP/XLOOKUP) debido a espacios invisibles.
* **Sintaxis:** `=TRIM(rango)`

## Glosario de Términos Importantes

* **Sintaxis:** Estructura predeterminada y necesaria para que una función sea interpretada correctamente por la aplicación.
* **Cadena de texto (String):** Grupo de caracteres (letras, números o símbolos) dentro de una celda.
* **Subcadena:** Una parte específica extraída de una cadena de texto más grande.
* **Formato Condicional:** Herramienta que aplica estilos visuales (colores, bordes) a las celdas que cumplen reglas específicas.
