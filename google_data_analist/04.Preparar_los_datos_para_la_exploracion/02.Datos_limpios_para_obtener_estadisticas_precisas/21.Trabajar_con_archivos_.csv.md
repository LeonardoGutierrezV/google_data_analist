# Trabajar con archivos .csv

En un curso anterior de este programa de certificación, usted trabajó con archivos .csv. Los analistas de datos utilizan archivos .csv con frecuencia, por lo que a lo largo de este curso continuará utilizando archivos .csv para transferir datos a programas de análisis de datos para su posterior análisis y visualización. los archivos .csv son archivos de texto sin formato con una estructura de tabla organizada que incluye filas y columnas. Los valores de cada fila están separados por comas. Esta estructura de tabla facilita su comprensión, edición, manipulación y uso para el análisis de datos.

Una de las principales ventajas de los archivos .csv es su amplia compatibilidad, ya que pueden ser importados y exportados por una amplia gama de herramientas de análisis de datos y programas de software.

## Descargar archivos .csv

Para utilizar archivos .csv y cargarlos en programas de análisis de datos, primero tendrá que descargarlos en su dispositivo local. La descarga de un archivo .csv desde un sitio web puede variar en función de su sistema operativo o navegador de Internet. A continuación se indican algunas formas de descargar un archivo .csv:

* **Haz clic en el enlace de descarga o en el archivo .csv adjunto**: Localiza el enlace del archivo .csv o adjunto en el sitio web. Haga clic en él y se iniciará el proceso de descarga.

* **Haga clic con el botón derecho del ratón y guarde**: Haga clic con el botón derecho del ratón en la tabla de datos o en el elemento que contiene los datos .csv. Elija Guardar como... o una opción similar. Asigne un nombre al archivo y asegúrese de que la extensión del archivo es ".csv".

* **Fuerza la descarga**: Puedes utilizar la tecla Alt de tu teclado mientras haces clic en el enlace. Esto activará la descarga, y podrás encontrar el archivo .csv en tu carpeta de Descargas.

**Nota**: Si utilizas el navegador Chrome o ChromeOS, es posible que los archivos .csv se abran en una nueva pestaña en lugar de descargarse en tu equipo. Si esto ocurre, sigue estas instrucciones:

* Selecciona Archivo en la barra de menús y, a continuación, Guardar como Google Sheets. De este modo, el archivo .csv se abrirá como una hoja de Google.

* Selecciona Archivo en la barra de menús, luego selecciona Descargar en el menú desplegable y, a continuación, Valores separados por comas (.csv).

## Cargar archivos .csv
A menudo necesitará cargar archivos .csv durante el proceso de análisis de datos. A continuación se explica cómo hacerlo:

* **Localice la opción de carga**: Cada plataforma de análisis de datos tendrá un botón designado, una opción de menú o un área de arrastrar y soltar llamada Cargar o Importar. Aquí es donde cargará su archivo .csv.

* **Elija su archivo .csv**: Haga clic en Cargar o Importar en la plataforma que esté utilizando para abrir el explorador de archivos. Seleccione su archivo .csv. Si acaba de descargar un archivo .csv de la Web, se encontrará en la carpeta Descargas de su ordenador.

* **Inicie la carga**: Una vez seleccionado el archivo .csv, haz clic en Cargar o Importar. La plataforma puede mostrar una barra de progreso o un mensaje indicando que la carga se ha completado.

 **Nota**: Algunas plataformas tienen restricciones sobre el tamaño o el formato de los archivos .csv. Asegúrese de que sus archivos .csv cumplen estos requisitos antes de cargarlos.
