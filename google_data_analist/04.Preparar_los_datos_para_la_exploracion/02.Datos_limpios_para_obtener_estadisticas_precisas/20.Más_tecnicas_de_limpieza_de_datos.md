# Más técnicas de limpieza de datos

Hola. Hasta ahora, ha aprendido sobre muchas herramientas y funciones diferentes que los analistas utilizan para limpiar los datos para su análisis. Ahora daremos un paso atrás y hablaremos sobre algunos de los aspectos más generales de los datos limpios. Saber cómo solucionar problemas específicos, ya sea manualmente con herramientas de hojas de cálculo o con funciones, es extremadamente valioso. Pero también es importante pensar en cómo se han movido los datos entre sistemas y cómo han evolucionado a lo largo de su recorrido hasta su proyecto de análisis de datos. Para ello, los analistas de datos utilizan algo llamado mapeo de datos. El mapeo de datos es el proceso de hacer coincidir los campos de una base de datos con otra. Esto es muy importante para el éxito de la migración de datos, la integración de datos y muchas otras actividades de administración de datos. Como aprendió anteriormente, los diferentes sistemas almacenan los datos de diferentes maneras. Por ejemplo, el campo de estado de una hoja de cálculo puede mostrar Maryland escrito. Sin embargo, otra hoja de cálculo podría almacenarlo como MD. El mapeo de datos nos ayuda a observar este tipo de diferencias para que sepamos que cuando los datos se muevan y combinen serán compatibles. Como recordatorio rápido, la compatibilidad describe qué tan bien dos o más conjuntos de datos pueden trabajar juntos. El primer paso para el mapeo de datos es identificar qué datos se deben mover. Esto incluye las tablas y los campos que contienen. También necesitamos definir el formato deseado para los datos una vez que lleguen a su destino. Para averiguar cómo funciona esto, volvamos a la fusión entre nuestras dos asociaciones logísticas. Empezando por el primer campo de datos, identificaremos que necesitamos mover ambos conjuntos de ID de miembros. Para definir el formato deseado, elegiremos si usar números como esta hoja de cálculo o direcciones de correo electrónico como la otra hoja de cálculo. Luego viene el mapeo de los datos. Según el esquema y la cantidad de claves principales y externas de una fuente de datos, la asignación de datos puede ser simple o muy compleja. Como recordatorio, un esquema es una forma de describir cómo se organiza algo. Una clave principal hace referencia a una columna en la que cada valor es único y una clave externa es un campo de una tabla que es una clave principal de otra tabla. Para proyectos más desafiantes, hay todo tipo de programas de software de mapeo de datos que puede usar. Estas herramientas de mapeo de datos analizarán campo por campo cómo mover los datos de un lugar a otro y luego limpiarán, compararán, inspeccionarán y validarán automáticamente los datos. También crean convenciones de nomenclatura coherentes, lo que garantiza la compatibilidad cuando los datos se transfieren de una fuente a otra. Al seleccionar un programa de software para mapear los datos , asegúrese de que es compatible con los tipos de archivo con los que está trabajando, como Excel, SQL, Tableau y otros. Más adelante, obtendrá más información sobre cómo seleccionar la herramienta adecuada para una tarea en particular. Por ahora, practiquemos el mapeo manual de datos. En primer lugar, debemos determinar el contenido de cada sección para asegurarnos de que los datos terminen en el lugar correcto. Por ejemplo, los datos sobre cuándo caducan las membresías se consolidarían en una sola columna. Este paso garantiza que cada información termine en el lugar más adecuado de la fuente de datos combinada. Ahora, tal vez recuerde que algunos de los datos no eran consistentes entre las dos organizaciones, como el hecho de que una usa una columna separada para el número de unidad o apartamento de la suite, pero la otra no. Esto nos lleva al siguiente paso: transformar los datos en un formato coherente. Este es un buen momento para usar la concatenación. Como has aprendido antes, la concatenación es una función que une dos o más cadenas de texto, que es lo que hicimos anteriormente con el ejemplo de nuestra empresa de cosméticos. Insertaremos una nueva columna y, a continuación, escribiremos igual a concatenar, luego las dos cadenas de texto que queremos hacer una. Arrastra eso por toda la columna. Ahora tenemos la coherencia en las nuevas listas de asociaciones fusionadas de direcciones de miembros. Ahora que todo es compatible, es el momento de transferir los datos a su destino. Hay muchas formas diferentes de mover datos de un lugar a otro, incluidas las consultas, los asistentes de importación e incluso la simple función de arrastrar y soltar. Esta es nuestra hoja de cálculo combinada. Se ve bien, pero aun así queremos asegurarnos de que todo se transfirió correctamente. Entraremos en la fase de prueba del mapeo de datos. Para ello, inspecciona un fragmento de datos de muestra para confirmar que está limpio y tiene el formato correcto. También es una práctica inteligente comprobar al azar cosas como el número de valores nulos. Para la prueba, puedes usar muchas de las herramientas de limpieza de datos que analizamos anteriormente, como la validación de datos, el formato condicional, el COUNTIF, la clasificación y el filtrado. Por último, una vez que haya determinado que los datos están limpios y son compatibles, puede empezar a utilizarlos para el análisis. El mapeo de datos es muy importante porque incluso un solo error al combinar datos puede repercutir en toda la organización y provocar que el mismo error aparezca una y otra vez. Esto conduce a malos resultados. Por otro lado, la cartografía de datos puede salvar el día al proporcionarle una hoja de ruta clara que puede seguir para asegurarse de que sus datos lleguen de forma segura a su destino. Por eso aprendes a hacerlo.

# Mapeo y Migración de Datos: Garantizando la Integridad

Hasta ahora, has aprendido sobre muchas herramientas y funciones diferentes que los analistas utilizan para limpiar los datos. Ahora daremos un paso atrás para hablar sobre aspectos más generales: cómo se mueven los datos entre sistemas y cómo evolucionan en su recorrido.

### El Proceso de Mapeo de Datos

El **mapeo de datos** es el proceso de hacer coincidir los campos de una base de datos con otra. Es fundamental para el éxito de la migración y la integración de datos, ya que los diferentes sistemas almacenan la información de distintas maneras.

* **Identificación:** El primer paso es identificar qué tablas y campos deben moverse.
* **Definición de Formato:** Se debe definir cómo queremos que luzcan los datos al llegar a su destino (por ejemplo, decidir entre usar un ID numérico o un correo electrónico).
* **Compatibilidad:** Este concepto describe qué tan bien pueden trabajar juntos dos o más conjuntos de datos. El mapeo asegura que, al combinar la información, esta sea coherente (ej. Maryland vs. MD).

### Estructura y Herramientas Técnicas

Según el **esquema** y la cantidad de claves, la asignación puede ser simple o compleja.

* **Claves:**
* **Clave Principal:** Una columna donde cada valor es único.
* **Clave Externa:** Un campo que es clave principal en otra tabla, creando una relación entre ellas.


* **Software de Mapeo:** Existen programas que analizan campo por campo cómo mover los datos, limpiándolos y validándolos automáticamente. Es vital que estas herramientas sean compatibles con tus archivos (Excel, SQL, Tableau, etc.).

### Ejecución y Transformación

Para lograr consistencia, a veces es necesario realizar transformaciones manuales:

1. **Consolidación:** Asegurarse de que cada sección de datos termine en el lugar correcto (ej. fechas de caducidad en una sola columna).
2. **Transformación:** Convertir datos a un formato coherente.
* *Ejemplo:* Si una tabla tiene el número de departamento separado y la otra no, usamos la **concatenación** para unir las cadenas de texto y estandarizar las direcciones.


3. **Transferencia:** Una vez que todo es compatible, los datos se mueven mediante consultas, asistentes de importación o arrastrando archivos.

### Fase de Prueba y Validación

Incluso tras la transferencia, es obligatorio realizar pruebas:

* Inspeccionar una **muestra de datos** para confirmar el formato.
* Comprobar al azar el número de **valores nulos**.
* Utilizar herramientas como validación de datos, formato condicional, `COUNTIF`, clasificación y filtrado.

> **Conclusión:** Un solo error al combinar datos puede repercutir en toda la organización. El mapeo de datos actúa como una hoja de ruta para que la información llegue segura y precisa a su destino.

## Conceptos Clave y Definiciones

| Concepto | Definición |
| --- | --- |
| **Mapeo de Datos** | Proceso de vincular campos de una fuente de datos con campos de una fuente de destino para asegurar su correspondencia. |
| **Migración de Datos** | El proceso de trasladar datos de un sistema o formato de almacenamiento a otro. |
| **Compatibilidad** | La capacidad de dos o más conjuntos de datos para integrarse y funcionar juntos sin conflictos de formato o lógica. |
| **Esquema** | La estructura u organización lógica de una base de datos que define cómo se relacionan los datos entre sí. |
| **Clave Principal** | Un identificador único para un registro dentro de una tabla de base de datos (no se puede repetir). |
| **Clave Externa** | Un campo en una tabla que conecta con la clave principal de otra tabla, estableciendo un vínculo entre ambas. |
| **Concatenación** | Función que permite unir dos o más cadenas de texto independientes en una sola celda o campo. |
| **Valores Nulos** | Espacios en blanco o falta de datos en un campo; su presencia no deseada puede afectar la precisión del análisis. |
| **Validación de Datos** | Proceso de verificar que los datos ingresados o migrados cumplen con las reglas y formatos establecidos. |
