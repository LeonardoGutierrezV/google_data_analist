## Ejemplo 1: Utilizar el formato condicional para resaltar las celdas en blanco

El formato condicional es una herramienta de la hoja de cálculo que cambia el aspecto de las celdas cuando los valores cumplen determinadas condiciones.

1. Abra la hoja de cálculo [Logistics Association Memberships: Data for Cleaning](/google_data_analist/04.Preparar_los_datos_para_la_exploracion/assets/Logistics-Association-Memberships--Data-for-Cleaning.xlsx). 

2. Selecciona el rango de celdas al que aplicarás el formato condicional. En este ejemplo, seleccionarás las columnas de la A a la L, excepto las columnas F y H. Para seleccionar todas las columnas excepto F y H: a. Selecciona la celda A para resaltar la columna A. b. Mantén pulsada la tecla MAYÚS y al mismo tiempo utiliza el ratón para seleccionar la celda E. Esto resaltará todas las columnas entre A y E. c. Para seleccionar el resto de las columnas, mantén pulsada la tecla CONTROL (Windows) o COMANDO (Mac) mientras seleccionas las celdas G, I, J, K y L. d. Las columnas A a L de tu hoja de cálculo deberían estar resaltadas excepto la Columna F y la Columna H. 

3. En el menú, selecciona Formato y, a continuación, Formato condicional. Las columnas que has seleccionado deberían adquirir un tono verde claro y aparecerá una nueva herramienta Reglas de formato condicional. Además, el campo Aplicar a rango debería indicar las celdas que has seleccionado. 

4. A continuación, aplica una condición a estas celdas para cambiar el color de la celda si está vacía. En el desplegable Formatear celdas si, selecciona Celda está vacía.

5. Selecciona el campo Estilo de formato. Selecciona un color brillante del desplegable para que las celdas vacías destaquen.

6. Selecciona Hecho.

## Ejemplo 2. Eliminar duplicados Eliminar duplicados

Eliminar duplicados es una herramienta de hoja de cálculo que busca y elimina automáticamente las entradas duplicadas de una hoja de cálculo. Esto es más rápido y sencillo que buscar los datos desplazándose por ellos.

1. Cree una copia de su conjunto de datos haciendo clic con el botón derecho del ratón en la pestaña de miembros de la Asociación ABC y seleccionando Duplicar. Esta es una buena práctica, ya que evita que se borren accidentalmente datos importantes. Siga trabajando en la nueva hoja, Copia de los miembros de la Asociación ABC.

2. En el menú, seleccione Datos, luego Limpieza de datos, luego Eliminar duplicados.

3. Marque la casilla junto a Datos tiene fila de encabezado.

4. Marque la casilla junto a Seleccionar todo para inspeccionar toda la hoja de cálculo.

5. Selecciona Eliminar duplicados.

## Ejemplo 3: Dar formato a las fechas de forma coherente

Da formato a las fechas para que todos los datos de tu hoja de cálculo sean coherentes. Esto hace que los elementos sean más fáciles de encontrar y manipular.

1. Selecciona la columna J (Afiliación válida hasta), que contiene fechas.

2. En el menú, selecciona Formato, Número y Fecha.

## Ejemplo 4: Utilizar la división para separar datos en columnas

La opción de menú dividir es útil cuando tiene más de un dato en una celda y desea separar esos datos en celdas diferentes. 

1. Seleccione la columna L (Certificación). 

2. En el menú, seleccione Datos y, a continuación, Dividir texto en columnas.

3. El delimitador (por ejemplo, una coma) se detectará automáticamente. 

4. Si es necesario, especifique el separador manualmente en el desplegable que aparece en la hoja de cálculo.

## Ejemplo 5: Utilizar la división para fijar números almacenados como texto

SPLIT es una función de hoja de cálculo que divide el texto alrededor de un carácter especificado y coloca cada fragmento en una celda nueva y separada.

1. Abra la hoja de cálculo [Cosmetics Inc:Data for Cleaning](/google_data_analist/04.Preparar_los_datos_para_la_exploracion/assets/Cosmetics-Inc--Data-for-Cleaning.xlsx).

2. Observa que la celda F12 contiene un error.

3. Selecciona la columna E (Pedidos).

4. En el menú selecciona Datos, luego selecciona Dividir texto en columnas.

5. Esto elimina las comillas de la celda E12 para que la hoja de cálculo reconozca los datos de la celda como un número. Esto resuelve el error en la celda F12.
