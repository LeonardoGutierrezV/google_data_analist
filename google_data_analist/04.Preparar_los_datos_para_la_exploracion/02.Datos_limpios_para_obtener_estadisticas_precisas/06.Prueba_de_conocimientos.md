# Pon a prueba tus conocimientos sobre limpieza de datos

1. ¿Qué profesionales de datos son los responsables más frecuentes de garantizar que los datos estén disponibles, seguros y que se realicen copias de seguridad para evitar su pérdida?

   <span style="color:#00a32c">**Especialistas en almacenamiento de datos</span>

        Los especialistas en almacenamiento de datos se aseguran de que los datos estén disponibles, seguros y de que se realicen copias de seguridad para evitar pérdidas. Lo hacen desarrollando procesos y procedimientos para almacenar y organizar los Datos de forma eficaz. 

2. Rellene el espacio en blanco: Si un conjunto de datos contiene _____, es una indicación de que esos valores no existen en el conjunto de datos.

   <span style="color:#00a32c">**nulos**</span>

        Si un conjunto de datos contiene nulos, es una indicación de que esos valores no existen en el conjunto de datos.

3. Un profesional de datos trabaja en una columna de una hoja de cálculo que sólo puede contener números de identificación de clientes de seis dígitos. Se aseguran de que los puntos de datos de la columna tengan siempre exactamente seis dígitos utilizando ¿qué herramienta de análisis de datos?

   <span style="color:#00a32c">**Longitud de campo**</span>

        Garantizan que los valores de la columna tengan siempre exactamente seis dígitos mediante la longitud de campo. Longitud de campo determina cuántos caracteres pueden introducirse en un campo de una hoja de cálculo.

4. Rellene el espacio en blanco: La Validación de datos es una herramienta para comprobar la _____ de los datos antes de añadirlos o importarlos.

   <span style="color:#00a32c">**exactitud y Calidad**</span>

        La Validación de datos es una herramienta para comprobar la exactitud y la calidad de los datos antes de añadirlos o importarlos.
