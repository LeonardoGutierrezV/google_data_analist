# ¿Qué son los datos sucios?

Antes hemos hablado de que los Datos sucios son datos **incompletos**, **incorrectos** o **irrelevantes** para el problema que intenta resolver. Esta lectura lo resume:

* Tipos de Datos sucios que puede encontrar

* Qué puede haber causado que los datos se ensucien

* Cómo perjudican los datos sucios a las empresas

## Tipos de datos sucios

Los 6 tipos de datos sucios: datos duplicados, desfasados, incompletos, incorrectos e incoherentes

### Datos duplicados

#### Descripción

Cualquier registro de Datos que aparezca más de una vez

#### Posibles causas

Introducción manual de datos, importación de datos por lotes o migración de datos

#### Perjuicio potencial para las empresas (Business-to-Business)

Métricas o análisis sesgados, recuentos o predicciones inflados o inexactos, o confusión durante la recuperación de datos

### Datos desactualizados

#### Descripción

Datos antiguos que deberían sustituirse por información más reciente y precisa

#### Posibles causas

Personas que cambian de función o de empresa, o software y sistemas que se quedan obsoletos

#### Perjuicio potencial para los negocios (Business-to-Business)

Información, toma de decisiones y análisis de datos imprecisos

### Datos incompletos

#### Descripción

Datos a los que les faltan campos importantes

#### Posibles causas

Recogida de datos inadecuada o introducción de datos incorrectos

#### Perjuicio potencial para las empresas (Business-to-Business)

Disminución de la productividad, inexactitud de las estadísticas o incapacidad para completar los servicios esenciales

### Datos incorrectos/inexactos

#### Descripción

Datos completos pero inexactos

#### Posibles causas

Error humano insertado durante la introducción de datos, información falsa o datos simulados

#### Perjuicio potencial para las empresas (Business-to-Business)

Perspectivas imprecisas o toma de decisiones basada en información errónea que provoque pérdidas de Ingresos

### Datos incoherentes

#### Descripción

Datos que utilizan formatos diferentes para representar lo mismo

#### Posibles causas

Datos almacenados incorrectamente o errores insertados durante la transferencia de datos

#### Perjuicio potencial para las empresas (Business-to-Business)

Datos contradictorios que provocan confusión o incapacidad para clasificar o segmentar a los clientes

## Impacto empresarial de los Datos sucios

Si desea leer más sobre el impacto empresarial de los Datos sucios, introduzca el término "datos sucios" en la barra de búsqueda de su navegador preferido para que aparezcan numerosos artículos sobre el tema. He aquí algunos impactos citados para determinadas industrias a partir de una búsqueda anterior:

* **Banca**: Las imprecisiones cuestan a las empresas entre un 15% y un 25% de los Ingresos ([fuente](https://sloanreview.mit.edu/article/seizing-opportunity-in-data-quality/)). 

* **Comercio digital**: Hasta el 25% de los contactos de las bases de datos B2B contienen inexactitudes ([fuente](https://www.demandgen.com/dirty-data-what-is-it-costing-you/)).

* **Marketing y ventas**: El 99% de las empresas abordan activamente la calidad de los datos de alguna manera([fuente](https://www.dqglobal.com/blog/why-bad-data-is-wasting-your-marketing-efforts/)). 

* Sanidad**: Los registros duplicados pueden suponer el 10% e incluso hasta el 20% de los registros sanitarios electrónicos de un hospital([fuente](https://searchhealthit.techtarget.com/feature/Hospitals-battle-duplicate-medical-records-with-technology)).

## Puntos clave
Los Datos sucios incluyen datos duplicados, Datos desactualizados, Datos incompletos, Datos incorrectos/inexactos y Datos incoherentes. Cada tipo de datos sucios puede tener un impacto significativo en los análisis, dando lugar a una visión imprecisa, una toma de decisiones pobre y una pérdida de Ingresos. Hay una serie de causas de los datos sucios, incluidos los errores de introducción manual de datos, las importaciones de datos por lotes, la migración de datos, la obsolescencia del software, la recopilación inadecuada de datos y los errores humanos durante la introducción de datos. Como profesional de los datos, puede tomar medidas para mitigar el impacto de los Datos sucios implementando procesos eficaces de calidad de datos.
