# Glosario de términos del módulo 2

## Términos y definiciones para el Curso 4, Módulo 2

**Datos limpios**: Datos completos, correctos y pertinentes para el problema que se está resolviendo

**Compatibilidad**: capacidad de dos o más conjuntos de datos para trabajar juntos

**CONCATENAR**: función de una hoja de cálculo que une dos o más cadenas de texto

**Formato condicional**: Herramienta de la hoja de cálculo que cambia el aspecto de las celdas cuando los valores cumplen determinadas condiciones

**Ingeniero de datos**: Profesional que transforma los datos en un formato útil para el análisis y los dota de una infraestructura fiable

**Mapeo de datos**: Proceso de hacer coincidir campos de una fuente de datos con otra

**Fusión de datos**: Proceso de combinar dos o más conjuntos de datos en uno solo

**Validación de datos**: Herramienta para comprobar la exactitud y calidad de los datos

**Especialista en almacenamiento de datos**: Profesional que desarrolla procesos y procedimientos para almacenar y organizar datos de forma eficaz

**Delimitador**: Carácter que indica el principio o el final de un dato

**Datos sucios**: Datos incompletos, incorrectos o irrelevantes para el problema que hay que resolver

**Datos duplicados**: Cualquier registro que inadvertidamente comparta datos con otro registro

**Longitud de campo**: Herramienta para determinar cuántos caracteres pueden introducirse en un campo de una hoja de cálculo

**Datos incompletos**: Datos a los que les faltan campos importantes

**Datos incoherentes**: Datos que utilizan distintos formatos para representar lo mismo

**Datos incorrectos/inexactos**: Datos completos pero inexactos

**LEFT**: Función que devuelve un número determinado de caracteres de la parte izquierda de una cadena de texto.

**LEN**: Función que devuelve la longitud de una cadena de texto contando el número de caracteres que contiene

**Longitud**: El número de caracteres de una cadena de texto

**Fusión**: Acuerdo que une dos organizaciones en una sola nueva

**MID**: función que devuelve un segmento del centro de una cadena de texto

**Nulo**: Indicación de que un valor no existe en un conjunto de datos

**Datos desactualizados**: Cualquier dato que ha sido sustituido por información más reciente y precisa

**Quitar duplicados**: Herramienta de hoja de cálculo que busca y elimina automáticamente las entradas duplicadas de una hoja de cálculo

**Dividir**: Función que divide el texto en torno a un carácter especificado y coloca cada fragmento en una celda nueva y separada

**SUBSTR**: Un subconjunto más pequeño de una Cadena de texto

**Cadena de texto**: Un grupo de caracteres dentro de una celda, a menudo compuesto por letras

**TRIM**: Función que elimina los espacios iniciales, finales y repetidos de los datos

**Único**: Un valor que no puede tener un duplicado
