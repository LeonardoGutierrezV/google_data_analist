Términos y definiciones para el Curso 4, Módulo 3
CAST: Función SQL que convierte datos de un tipo de datos a otro

COALESCE: Una función SQL que devuelve valores no nulos en una lista

CONCAT: Una función SQL que suma cadenas para crear nuevas cadenas de texto que pueden utilizarse como claves únicas

DISTINCT: palabra clave que se añade a una sentencia SELECT de SQL para recuperar sólo las entradas no duplicadas

Flotante: Un número que contiene un decimal

SUBSTR: Subconjunto de una cadena de texto

Tipificación: Conversión de datos de un tipo a otro
