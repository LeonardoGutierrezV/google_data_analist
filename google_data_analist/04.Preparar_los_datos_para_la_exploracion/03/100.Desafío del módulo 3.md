# Desafío del módulo 3

1. Tras la fusión de una empresa, un Analista de datos recibe un Conjunto de datos con millones de filas de datos. Necesita utilizar estos Datos para identificar estadísticas para un proyecto importante. ¿Qué herramienta sería la más eficaz para el analista?

  <span style="color:#00a32c">**SQL**</span>

2. Un profesional de datos junior se da cuenta de que su columna booleana está almacenando incorrectamente los valores Verdadero/Falso como cadenas. ¿Qué función SQL puede utilizar el analista para convertir el tipo de datos de Cadena a Booleano?

  <span style="color:#00a32c">**CAST**</span>

3. Rellene el espacio en blanco: Un Equipo de datos que colabora con el departamento de RRHH utiliza el comando SQL _____ para añadir una fila de un nuevo empleado a la base de datos de su organización.

  <span style="color:#00a32c">**INSERT INTO**</span>

4. Está trabajando con una tabla de base de datos que tiene columnas sobre árboles, como tree_species. ¿Qué función de SUBSTR y comando de AS recuperará los 3 primeros caracteres del nombre de cada especie y almacenará el resultado en una nueva columna llamada species_ID?

  <span style="color:#00a32c">**SUBSTR(tree_species, 1, 3) AS species_ID**</span>

5. En SQL, ¿qué función puede utilizarse para eliminar los espacios finales de un dato? 

  <span style="color:#00a32c">**TRIM**</span>

6. Mientras trabaja con una tabla de base de datos que contiene la columna nombre_empleado, observa que hay algunas entradas duplicadas. ¿Qué cláusula SQL utilizaría en una consulta para devolver los datos de nombre_empleado sin estos duplicados? 

  <span style="color:#00a32c">**DISTINCT employee_name**</span>

7. Rellene el espacio en blanco: Un analista de datos utiliza el comando SQL _____ para eliminar las tablas innecesarias y que no abarroten la base de datos de su organización. 

  <span style="color:#00a32c">**DROP TABLE IF EXISTS**</span>

8. Está utilizando una tabla de base de datos que incluye la columna número_cuenta y quiere asegurarse de que los datos son coherentes. ¿Qué cláusula SQL le ayudará a identificar los números de cuenta de más de 8 caracteres?

  <span style="color:#00a32c">**LENGTH(account_number) > 8**</span>

9. Al migrar datos de un sistema heredado a una nueva base de datos, descubre que muchos registros de clientes contienen valores nulos en la columna email_address. ¿Qué función SQL puede utilizar para sustituir estos valores nulos por un valor en una columna diferente?

  <span style="color:#00a32c">**COALESCE**</span>
