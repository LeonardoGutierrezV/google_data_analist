# Añada Habilidades técnicas a su Currículum

Las competencias técnicas son cruciales a la hora de elaborar un currículum sólido. Demuestran a los empleadores que posees las habilidades necesarias para desempeñar con éxito el trabajo. Piense en las competencias técnicas como si fueran su caja de herramientas: La forma en que enumeras cada habilidad en tu currículum es la forma en que demuestras a los empleadores que eres capaz de utilizar esas herramientas.

Conocimientos técnicos comunes para los analistas de datos principiantes
Se necesitan muchas habilidades para ser un analista de datos de éxito, y éstas son algunas de las más comunes que los empleadores buscan a la hora de contratar analistas de datos:


1. Lenguaje de consulta estructurado (SQL): SQL se considera una habilidad básica que es fundamental para cualquier puesto de analista de datos de nivel inicial. SQL te ayuda a comunicarte con las bases de datos y, más concretamente, está diseñado para ayudarte a recuperar información de las bases de datos. Cada mes, miles de ofertas de trabajo de analista de datos requieren SQL, y saber utilizar SQL sigue siendo una de las funciones más comunes de un analista de datos.

2. Hojas de cálculo: Aunque SQL es popular, el 62% de las empresas siguen prefiriendo utilizar hojas de cálculo para obtener información sobre sus datos. Cuando consigas tu primer trabajo como analista de datos, la primera versión de tu base de datos puede estar en forma de hoja de cálculo, que sigue siendo una herramienta potente para elaborar informes o incluso para presentar conjuntos de datos. Por lo tanto, es importante que estés familiarizado con el uso de hojas de cálculo para el análisis de datos.

3. Herramientas de visualización de datos: Las herramientas de visualización de datos ayudan a simplificar datos complejos y permiten que los datos se entiendan visualmente. Tras recopilar y analizar los datos, los analistas de datos tienen la tarea de presentar sus conclusiones y hacer que la información sea fácil de comprender. Entre las herramientas más utilizadas en el análisis de datos se encuentran Tableau, Microstrategy, Data Studio, Looker, Datarama, Microsoft Power BI y muchas más. Entre ellas, Tableau es la más conocida por su facilidad de uso, por lo que es imprescindible para los analistas de datos principiantes. Además, los estudios muestran que se espera que los trabajos de análisis de datos que requieren Tableau crezcan alrededor de un 34,9% durante la próxima década.

4. Programación en Python: Aunque no es necesario ser un experto en lenguajes de programación como analista de datos principiante, entender los fundamentos de Python es una gran ventaja. Python es el lenguaje de programación más utilizado entre los analistas de datos, y los conocimientos de Python que aprenderás en un curso posterior serán una herramienta valiosa para el análisis de datos. 

Nota: R también es un gran complemento a tener en cuenta a medida que avanzas en tu carrera.

Puntos clave
Como analista de datos, a menudo se le pide que recopile y analice datos con un propósito específico en mente. Saber qué plataforma y qué lenguaje utilizar le ayudará a analizar los datos para descifrar qué información es importante, buscar anomalías, preparar preguntas, evaluar riesgos y mucho más.
