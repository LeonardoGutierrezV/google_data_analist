## Ejemplo 1: Verificar datos con hojas de cálculo

Utiliza herramientas de hojas de cálculo como Buscar y reemplazar y tablas dinámicas para encontrar, comprender y corregir errores en tu hoja de cálculo. 

**Buscar y reemplazar para reemplazar todas las instancias de un error**
1. Utilice el conjunto de datos [Jeff's Party Planet - Datos para limpiar](https://docs.google.com/spreadsheets/d/1RaDdSEp2V6D09FE6LOFkiJGv9CMT83GIV_U9YnY2rvI/template/preview?resourcekey=0-IU2-k90CX0mrt0ebwrvwDw#gid=0).

2. En el menú Edición , seleccione Buscar y reemplazar para abrir el cuadro de diálogo Buscar y reemplazar . 

3. En el campo Buscar , introduzca la palabra mal escrita en el nombre del proveedor, Plos. 

4. En el campo Reemplazar por , introduzca Más. 

5. Haga clic en Reemplazar todo para reemplazar todas las instancias de "Plos" por "Plus".  Haga clic en Listo para cerrar el cuadro de diálogo Buscar y reemplazar. 

6. Seleccione el botón Deshacer para utilizar un método diferente para corregir este error ortográfico. Esto también puede hacerse con Ctrl (Windows) o Comando (MAC) Z.

### Utilizar una Tabla dinámica para comprender errores en una hoja de cálculo

1. Seleccione la columna Proveedores .

2. Selecciona Insertar > Tabla dinámica. En el cuadro de diálogo Crear tabla dinámica , seleccione Nueva hoja y, a continuación, Crear. 

3. Esto crea una nueva hoja que en su mayor parte está en blanco.

4. Además, en la ventana aparece el panel Editor de tablas dinámicas.  

5. Al lado de Filas. Seleccione Agregar, luego la columna Proveedores . 

6. Junto a Valores, seleccione Agregar y luego Proveedores. Esto añade un valor para la columna Proveedores .

7. Por defecto, Google Sheets establece el valor para resumir por COUNTA  (el número total de valores en un rango). Esto mostrará cuántas veces aparece el nombre de cada proveedor. Es una buena forma de comprobar si hay errores ortográficos u otras anomalías. Nota: No utilice COUNT, porque COUNT sólo cuenta valores numéricos.

8. Cuando sólo aparezca un nombre mal escrito, cámbielo manualmente por el correcto.

9. Para volver a la hoja original, seleccione la pestaña Hoja1 . 

## Ejemplo 2: Utilizar una sentencia CASE para verificar datos en SQL

Utilice las sentencias CASE para corregir errores ortográficos en SQL.

1. La tabla SQL utilizada en este ejemplo no está disponible para su descarga, pero si estuviera realizando una consulta similar, primero se aseguraría de cargar los datos en BigQuery. 

2. Comience su consulta SQL con la estructura básica: 

```sql
SELECT 

FROM

WHERE 
```

3. En la cláusula FROM, especifica la tabla de la que estás extrayendo datos después de FROM. Por ejemplo, project-id.customer_data.customer_name

4. En la cláusula SELECT, especifique las columnas que desea devolver. En este ejemplo, desea customer_id y first_name. 

5. Sin embargo, hay un error ortográfico en el nombre de pila de un cliente. 

	i. Para corregir el nombre mal escrito "Tnoy" a "Tony", utilice una sentencia CASE.

	ii. Introduzca CASE. En la línea siguiente, introduzca WHEN first_name = 'Tnoy'THEN 'Tony'. Esto indica a SQL que sustituya cualquier instancia de Tnoy en la columna first_name por Tony. 

	iii. En la línea siguiente, añada statement ELSE first_name para mantener los demás nombres como están.

	iv. Termine la sentencia con END AS cleaned_name. Esto crea una nueva columna llamada cleaned_name que contendrá los datos limpiados con la sentencia CASE. 

6. Elimine la cláusula WHERE porque no desea filtrar la consulta.

7. La sentencia final debería ser:

```sql
SELECT
    Customer_id,
    CASE
	WHEN first_name = 'Tnoy' THEN 'Tony'
	ELSE first_name
	END AS cleaned_name
FROM
```
   project-id.customer_data.customer_name
8. Esta consulta SQL corregirá el nombre mal escrito y dejará los demás nombres sin modificar en una nueva columna llamada cleaned_name. Tenga en cuenta que esta consulta sólo corrige la visualización del nombre; no actualiza los datos de la tabla.
