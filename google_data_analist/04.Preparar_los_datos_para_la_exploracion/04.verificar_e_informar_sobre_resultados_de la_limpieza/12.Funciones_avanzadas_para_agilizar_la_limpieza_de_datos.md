## Mantener los datos limpios y sincronizados con una fuente

Tanto la función [IMPORTRANGE](https://support.google.com/docs/answer/3093340?hl=en) de Google Sheets como la función  [PasteLink](https://professor-excel.com/how-to-paste-cell-links/) (una opción de Pegado especial de Microsoft Excel) le permiten insertar datos de una hoja a otra. Utilizarlas con una gran cantidad de Datos es más eficaz que copiar y pegar manualmente. También reducen la posibilidad de que se introduzcan errores al copiar y pegar los datos equivocados. También son útiles para la limpieza de datos porque puede "seleccionar" los datos que desea analizar y dejar atrás los que no son relevantes para su proyecto. Básicamente, es como cancelar el ruido de sus datos para que pueda centrarse en lo más importante para resolver su problema. Esta funcionalidad también es útil para el seguimiento diario de los datos; con ella, puede construir una hoja de cálculo de seguimiento para compartir los datos relevantes con otras personas. Los datos se sincronizan con la fuente de datos, de modo que cuando los datos se actualizan en el archivo de origen, los datos de seguimiento también se actualizan. 

En Google Sheets, puede utilizar la función IMPORTRANGE. Le permite especificar un Rango de celdas en la otra hoja de cálculo para duplicarlo en la hoja de cálculo en la que está trabajando. Debe permitir el acceso a la hoja de cálculo que contiene los Datos la primera vez que importe los Datos.

La URL que se muestra a continuación es sólo a efectos de sintaxis. No la introduzca en su propia hoja de cálculo. Sustitúyala por la URL de una hoja de cálculo que haya creado para poder controlar el acceso a la misma haciendo clic en el botón Permitir acceso.

# Ejemplo de uso IMPORTRANGE

Un analista que supervisa una recaudación de fondos necesita hacer un seguimiento y asegurarse de que se distribuyen los fondos de contrapartida. Utilizan IMPORTRANGE para extraer todas las transacciones de contrapartida en una hoja de cálculo que contiene todas las donaciones individuales. Esto les permite determinar qué donaciones susceptibles de recibir fondos de contrapartida quedan por procesar. Como el número total de transacciones de contrapartida aumenta diariamente, sólo tienen que cambiar el Rango utilizado por la función para importar los datos más actualizados.

El martes, utilizan lo siguiente para importar los nombres de los donantes y los importes igualados:

**=IMPORTRANGE("https://docs.google.com/spreadsheets/d/abcd123abcd123", "sheet1!A1:C10", "Matched Funds!A1:B4001")**

El miércoles, se procesaron otras 500 transacciones. Aumentan el rango utilizado en 500 para incluir fácilmente las transacciones más recientes al importar los datos a la hoja de cálculo de donantes individuales:

**=IMPORTRANGE("https://docs.google.com/spreadsheets/d/abcd123abcd123", "Matched Funds!A1:B4501")**

**Nota**: Los ejemplos anteriores son meramente ilustrativos. No los copie y pegue en su hoja de cálculo. Para probarlo usted mismo, tendrá que sustituir su propia URL (y el nombre de la hoja si tiene varias pestañas) junto con el Rango de celdas de la hoja de cálculo que ha rellenado con datos. 

## Extracción de datos de otras fuentes de datos

La función [QUERY](https://support.google.com/docs/answer/3093343?hl=en) también resulta útil cuando desea extraer datos de otra hoja de cálculo. La capacidad similar a SQL de la función QUERY puede extraer datos específicos dentro de una hoja de cálculo. Para una gran cantidad de datos, utilizar la función QUERY es más rápido que filtrar los datos manualmente. Esto es especialmente cierto cuando se requiere un filtrado repetido. Por ejemplo, podría generar una Lista de todos los clientes que compraron los productos de su empresa en un mes concreto utilizando el filtrado manual. Pero si también quiere averiguar el crecimiento de los clientes mes a mes, tendrá que copiar los datos filtrados a una nueva hoja de cálculo, filtrar los datos para las ventas del mes siguiente y, a continuación, copiar esos resultados para el análisis. Con la función QUERY, puede obtener todos los datos de ambos meses sin necesidad de cambiar su conjunto de datos original ni de copiar los resultados.

La sintaxis de la función QUERY es similar a la de IMPORTRANGE. Usted introduce la hoja por su nombre y el rango de datos a partir del cual desea realizar la consulta y, a continuación, utiliza el comando SQL SELECT para seleccionar las columnas específicas. También puede añadir criterios específicos después de la sentencia SELECT incluyendo una sentencia WHERE. Pero recuerde, ¡todo el código SQL que utilice debe colocarse entre comillas!

Las hojas de cálculo de Google ejecutan el Lenguaje de consulta de la API de Visualización de datos de Google. Las hojas de cálculo de Excel utilizan un asistente de consulta que le guía por los pasos para conectarse a una fuente de datos y seleccionar las tablas. En cualquiera de los casos, podrá estar seguro de que los datos importados están verificados y limpios en función de los criterios de la consulta.

## La solución

Los analistas pueden utilizar SQL para extraer un conjunto de datos específico en una hoja de cálculo. A continuación, pueden utilizar la función QUERY para crear varias pestañas (vistas) de ese conjunto de datos. Por ejemplo, una pestaña podría contener todos los datos de ventas de un mes concreto y otra pestaña podría contener todos los datos de ventas de una región específica. Esta solución ilustra el buen uso conjunto de SQL y las hojas de cálculo.

## Filtrado de datos para obtener lo que desea

La función [FILTER](https://support.google.com/docs/answer/3093197?hl=en) es totalmente interna a una hoja de cálculo y no requiere el uso de un lenguaje de consulta. La función FILTER le permite ver sólo las filas (o columnas) de los datos de origen que cumplen las condiciones especificadas. Permite prefiltrar los datos antes de analizarlos.

La función FILTER puede ejecutarse más rápidamente que la función QUERY. Pero tenga en cuenta que la función QUERY puede combinarse con otras funciones para realizar cálculos más complejos. Por ejemplo, la función QUERY puede utilizarse con otras funciones como SUM y COUNT para resumir datos, pero la función FILTER no.
