# Proceso de Verificación y Limpieza Automatizada

El objetivo de la verificación es garantizar que el trabajo de limpieza de datos se haya realizado correctamente y que los resultados sean 100% confiables. Es comparable a las pruebas de seguridad que realizan las empresas automovilísticas antes de lanzar un coche al mercado.

### Pasos en la Verificación

1. **Comparación Inicial:** Regresar al conjunto de datos original ("sucio") y compararlo con el conjunto actual para detectar problemas comunes.
2. **Limpieza Manual:** Corregir errores puntuales como espacios sobrantes o comillas accidentales.
3. **Uso de Herramientas Automáticas:** Emplear funciones y herramientas integradas para procesar grandes volúmenes de datos.

### Herramientas en Hojas de Cálculo

* **TRIM y Quitar Duplicados:**
* **TRIM** elimina espacios innecesarios.
* **Quitar Duplicados** purga automáticamente registros repetidos.


* **Buscar y Reemplazar:**
* Permite localizar un término específico (como un error ortográfico) y sustituirlo en toda la hoja de cálculo de una sola vez.


* **Tablas Dinámicas:**
* Útiles para verificar si un error es un hecho puntual o sistemático. Por ejemplo, si esperas 4 proveedores y la tabla muestra 5, existe un error de escritura.



### Verificación y Limpieza en SQL

Cuando se trabaja con bases de datos, la limpieza se puede integrar directamente en la consulta:

* **Sentencia CASE:**
* Permite establecer condiciones lógicas. Si el sistema encuentra un dato mal escrito (ej. "Tnoy"), puede transformarlo automáticamente en el resultado correcto (ej. "Tony") antes de mostrar el informe final.
* **Sintaxis:** Se utiliza `WHEN` para la condición, `THEN` para el resultado deseado y `ELSE` para mantener los datos que ya están correctos.

## Conceptos Clave y Definiciones

| Concepto | Definición |
| --- | --- |
| **Verificación** | Proceso final de confirmación para asegurar que los datos están limpios, son precisos y están listos para el análisis. |
| **Buscar y Reemplazar** | Herramienta que localiza caracteres o palabras específicas y los sustituye por otros nuevos en todo el documento. |
| **Tabla Dinámica** | Herramienta de resumen que agrupa y reorganiza datos para realizar cálculos como conteos, sumas o promedios rápidamente. |
| **COUNTA (CONTARA)** | Función que cuenta el número total de celdas que contienen cualquier tipo de información (texto o números) en un rango. |
| **COUNT (CONTAR)** | Función que cuenta únicamente las celdas que contienen valores numéricos dentro de un rango determinado. |
| **Sentencia CASE** | Estructura lógica en SQL que actúa como un condicional (si esto, entonces aquello) para devolver valores específicos basados en criterios. |
| **Cláusula SELECT** | Comando en SQL utilizado para especificar exactamente qué columnas de datos se desean extraer de una tabla. |
| **Cláusula FROM** | Comando en SQL que indica la tabla o ubicación de donde se deben extraer los datos. |
| **Alias (AS)** | Palabra clave en SQL utilizada para dar un nombre temporal y más legible a una columna en los resultados de una consulta. |
